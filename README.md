A complete GTA 6 trophy guide and tracker for PlayStation 5. Features a checklist of all 55 trophies with progress saved in localStorage, export/import functionality, filters by kind (story, missable, collectibles, activities), spoiler setting for story trophies, and a platinum roadmap showing the order to earn all trophies.

Run it:

```bash
node serve.ts
```

Then open http://localhost:8080
